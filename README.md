# JavaScript Assignments & Mini Project

This repository contains six JavaScript practical assignments and the capstone mini project described in the provided curriculum PDF.

## Contents
- `assignments/assignment1.js` — Variables, data types, and console operations
- `assignments/assignment2.js` — Operators, expressions, and input handling
- `assignments/assignment3.js` — Conditional logic
- `assignments/assignment4.js` — Loops and flow control
- `assignments/assignment5.js` — Functions and scope
- `assignments/assignment6.js` — Arrays, objects, and core methods
- `mini-project/index.html` — Browser-based interactive inventory dashboard
- `mini-project/style.css` — Dashboard styles
- `mini-project/app.js` — Inventory logic and analytics

## How to run the assignments
1. Install Node.js (if you do not already have it).
2. Open a terminal in this repository.
3. Run an assignment, for example:
   ```bash
   node assignments/assignment1.js
   ```
4. Assignment 2 uses `prompt()` in a browser. Open `assignments/assignment2.html` in a browser to use it.

## How to run the mini project
Open `mini-project/index.html` in a modern browser. You can add products, see budget/standard/premium categories, filter affordable items, and view inventory totals.

## Notes
- The original curriculum gives sample expected outputs. Where a browser prompt is required, input values affect the output.
- The mini project is implemented as a browser-based dashboard for easier demonstration, while using the JavaScript concepts specified in the curriculum.
