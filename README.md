# JavaScript Assignments & Mini Project

This repository contains six JavaScript practical assignments and a browser-based product inventory dashboard.

## Repository structure

### Assignments

Each assignment includes a JavaScript file and an HTML page that loads it:

- `assignments/assignment1.js` and `assignments/assignment1.html` — Variables, data types, and console output.
- `assignments/assignment2.js` and `assignments/assignment2.html` — Operators and expressions, with a prompt-based tip calculator.
- `assignments/assignment3.js` and `assignments/assignment3.html` — Conditional logic, grades, and pass/fail status.
- `assignments/assignment4.js` and `assignments/assignment4.html` — Loops and flow control.
- `assignments/assignment5.js` and `assignments/assignment5.html` — Functions, default parameters, and scope.
- `assignments/assignment6.js` and `assignments/assignment6.html` — Arrays, objects, and methods such as `forEach()`, `filter()`, and `map()`.

### Mini project

- `mini-project/index.html` — Dashboard page structure.
- `mini-project/style.css` — Responsive dashboard styling.
- `mini-project/app.js` — Inventory data, product actions, filters, categories, and analytics.

## Run the assignments

Open an assignment's HTML file in a modern browser. For example, open `assignments/assignment1.html`. The JavaScript output appears in the browser console; open developer tools with **F12**. Assignment 2 also prompts for the bill amount and tip percentage.

## Run the mini project

Open `mini-project/index.html` in a modern browser. You can add and remove products, filter by price category, and view the product count, total inventory value, average price, and formatted report.

The dashboard starts with a Laptop ($800) and Mouse ($25). Product changes are stored in memory and reset when the page is reloaded.
